nodalyze_engine

Модульный фреймворк для создания stateful ролевых ИИ-агентов и RP-движков.

Использует граф сцен (networkx) для детерминированных переходов без слома нарратива, Pydantic-валидацию с защитой от промпт-инъекций и отчистку системного жаргона в локальном Ollama/LLM окружении.

Python 3.10+ Ollama NetworkX Pydantic

YTubic-Unchained

Модифицированный форк оригинального плеера YTubic.

В этой версии полностью вырезана принудительная проверка наличия подписки YouTube Premium для комфортного прослушивания, а также интегрирован сервис LRCLIB для автоматического получения и синхронизации текстов песен.
